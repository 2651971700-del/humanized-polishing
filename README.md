# 人类化写作与精修 · Humanized Polishing

一个用于中文和英文学术文字的 Codex 技能，重点适配综述精修。先处理信息是否必要、论证是否清楚，再调整句子和措辞；保留作者原意、数字、终点、阴性结果及引用关系。

## 核心能力

- 删除事实之后没有新增信息的抽象复述。
- 识别机械对称与人为左右配平，保留真实的并列、主次和条件关系。
- 按逻辑单元合并或拆分句子，允许自然的长短节奏。
- 基于已提供的证据提炼跨研究比较，不编造差异原因。
- 取消没有新增判断的段尾总结，保持术语和证据强度一致。

## 安装

将本仓库目录保存为 `humanized-polishing`，放入 Codex 的技能目录：已设置 `CODEX_HOME` 时使用其下的 `skills` 目录，否则使用用户目录中的 `.codex/skills`。最终结构应为 `skills/humanized-polishing/SKILL.md`。

本技能由 Markdown 与 YAML 文件构成，无需安装 Python 包，也不依赖其他写作技能或外部检测服务。

## 使用

在支持该技能的任务中输入：

```text
请使用 $humanized-polishing 精修以下文字。
保留原意、数字和引用，按标准精修处理，直接给出修订正文；
如有证据疑点，单独列出。

【粘贴原文】
```

可指定“轻润色”“标准精修”“结构重写”或“仅诊断”，也可要求逐句对照。默认保持原文语言；翻译需要明确提出。

## 使用边界

人类化是编辑目标，不是作者身份判断。本技能不提供 AI 率或检测通过保证。润色不等于文献核验，示例中的虚构研究与数据不能用作科学证据。
