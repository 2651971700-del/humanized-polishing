# 跨研究综合：让判断来自证据

仅在综述、讨论、文献综合或跨研究比较时使用。本文件帮助形成可追溯的综合，不替代研究原文核验。

## 从研究清单到比较

先问本段想回答什么问题。围绕该问题比较已提供研究中的相关字段，不需要为短段落输出完整表格：

| 字段 | 应检查的内容 |
|---|---|
| 人群与场景 | 入组条件、疾病阶段、工作流程或应用环境是否一致 |
| 方法与时间 | 方法差异、实施时机、随访或观察窗口 |
| 对照与既有条件 | 原有流程已能做到什么，新增方法改变了什么 |
| 终点 | 报告时间、决策时间、治疗时间、生存结局等是否被混为一谈 |
| 证据性质 | 描述性结果、随机比较、观察性关联、探索性或亚组分析 |
| 支持范围 | 研究直接报告了什么，哪些只是作者解释，哪些未报告 |

仅凭摘要或用户转述，可以比较其中明确提供的信息；缺失字段标为未知，不假设各研究可比。不要将“未报告”写成“未发生”。

## 判断能否写入正文

候选判断应满足：

1. 能指出来自哪些研究及哪些具体事实。
2. 没有跨越人群、时间、终点或研究设计的边界。
3. 确实增加条件、差异、解释边界或证据缺口，而非再次重复结果。
4. 判断语气与支持程度一致：直接报告、跨研究综合和待检验解释应可区分。

研究间存在差异，并不能单凭差异证明某个条件导致结果不同。材料只支持一种解释可能性时，保留“可能”“尚不能区分”等限定；不要因删除“提示”而把推断改成定论。对原文已经过强的结论提出有依据的调整并说明，不自行改变作者的研究主张。

## 可用的综合方向

- **共同条件**：多项研究的收益是否只在某类人群或流程中出现？
- **差异来源**：结果差异是否可能与测量、终点、时点或比较对象不同有关？已有材料能否区分这些解释？
- **作用边界**：某项中间指标改善，是否已经落实到下一个动作或最终结局？
- **证据缺口**：材料明确未测量或未验证什么？证据不足不能自动写成无效。

这些是检查方向，不是要求每段凑齐四种判断。只有一项研究或比较依据不足时，准确转述也可以是最好的结果。

## 示意案例

以下均为虚构练习材料，不是医学结论，引用键仅作示例。

提供事实：A 研究的报告时间缩短，治疗启动时间未变；B 研究的报告时间和治疗启动时间均缩短。材料未说明两项研究的既有诊疗流程是否相同。

可写：

> A 研究缩短了报告时间，但治疗启动时间未变[@A]；B 研究中，两项时间指标均缩短[@B]。报告返回更早并不总是伴随治疗提前，现有材料尚不能确定两项研究的差异是否来自既有流程。

不可写：

> A 研究的组织分型已足够及时，因此血浆检测没有临床价值。

不可写的原因：既有流程没有提供，“没有临床价值”也扩大了原有终点的范围。

## 引用随判断分层

先让每个具体结果与其来源相邻，再检查综合判断是否由这些结果共同支持。不要给新推断随意加一个旧编号，制造“原研究已证明”的印象。重组后仍要保留所有独有证据的来源，不用增加引用密度掩盖缺少支撑。
