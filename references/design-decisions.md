# 本地整合依据与规则取舍

仅在解释本技能设计、维护规则或解决冲突时阅读。这里记录参考来源，不将其作为运行依赖，也不自动激活其他技能。

主要材料为用户提供的 `说明书.docx`：补充规则 9–12、十三步精修流程和四条核心原则。原材料针对一篇中文医学综述，本技能把可迁移规则用于后续文本；不把“以后这篇文章永远按此执行”等材料内表述当作对所有任务的无限授权。

本技能参考了本地已有的写作与编辑技能。下表记录主要参考及取舍；这些技能不构成运行依赖。

| 参考技能 | 吸收的部分 | 不移植为本技能要求的部分 |
|---|---|---|
| humanize | 学术语体、冗余模式、数字及引用保护 | 固定模式密度阈值、检测通过暗示、逐类修改审批、自动搬移披露 |
| writing-anti-ai | 中英文自然表达、节奏变化、减少空洞套话 | 为了人味添加感受、机械避开三项并列、主观评分充当可靠性证明 |
| article-logic-editor | 全文职责、顺序阅读、概念与证据对应 | 所有短文都生成多份审计文档、把润色自动扩大为结构重写 |
| nature-polishing | 读者理解优先、先逻辑后句子、区分结果和讨论 | 一律每句 10–30 词、固定段落收口、自动翻成英文 |
| polish-language | 术语、缩写和语言规范一致性 | 强制英文、重复审批、未取得原始依据就修改统计报告形式 |
| claim-strength-calibrator | 区分相关、因果、预测、验证与应用 | 对每个短段落强制生成长篇校准报告 |
| gerenxiezuo | 证据先于文风、写作与引文支持关系 | 自动启动全篇写作、文献搜索、多代理和参考文献数量目标 |

## 两个需要保留的边界

**左右配平不是并列结构禁令。** 说明书强调主动作与次要条件的区分，但新增“必要时”也可能改变原意。只有已知条件关系才改写为条件句；真实对照与等权并列继续保留。

**作者发现不是新增科学事实。** 允许把已提供研究之间的共同点、差异和边界写清楚；不能根据结果不同就虚构其原因。删掉“这提示”后，判断仍需保留原本的不确定性。

新技能采用独立的中文主规范与按需参考，默认直接完成用户授权的润色。没有添加模型专用路径、外部检测服务依赖或未经请求的长期配置修改。
